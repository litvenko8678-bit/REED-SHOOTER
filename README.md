REED: SHOOTER — Android FPS prototype

Features:
- Native Android project (Java + OpenGL ES 2.0)
- Landscape orientation
- Low-poly 3D arena
- First-person camera
- Five stationary bot targets
- Touch controls: left side moves, right side looks; tap right side to fire
- Kill counter and win condition

Build:
1. Open this folder in Android Studio.
2. Allow Gradle sync and install Android SDK Platform 35 + Build Tools.
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. APK output: app/build/outputs/apk/debug/app-debug.apk

Note: This environment has Java but no Android SDK, Gradle, or Android build tools, so an APK could not be compiled here. The complete editable Android project is included.
